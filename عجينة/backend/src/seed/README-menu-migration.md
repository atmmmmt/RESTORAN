# ترحيل منيو عجينة وطحينة

تتضمن حزمة الترحيل 153 منتجًا مختلفًا من المنيو القديمة، موزعة على 11 قسمًا فعليًا. حُذف
سجل واحد مكرر تمامًا بالاسم والسعر والقسم من المصدر. قسم
«فطيرات» موجود في المصدر لكنه فارغ، لذلك لا ينشئ الاستيراد منتجات وهمية له.

## الأوامر

```bash
# فحص البيانات فقط، دون الاتصال بقاعدة البيانات
npm run menu:check

# تنزيل صور المنتجات والأقسام إلى frontend/public/menu
npm run menu:assets

# إدخال المنتجات أو تحديثها في قاعدة البيانات المحددة في backend/.env
npm run menu:import

# تنزيل الصور ثم الاستيراد
npm run menu:migrate
```

الاستيراد آمن للتكرار: يطابق المنتج بواسطة الاسم والقسم، ثم يحدّث السعر والصورة
والوصف بدل إنشاء نسخة جديدة. المنتجات الجديدة تبدأ بمخزون 100 قطعة. يمكن تغيير
الكمية قبل الاستيراد بإضافة المتغير التالي إلى البيئة:

```env
LEGACY_MENU_INITIAL_STOCK=100
```

المنيو القديمة لا تحتوي أوصافًا مفصلة، لذلك يولّد الاستيراد وصفًا عربيًا مختصرًا
ومهنيًا حسب فئة المنتج. المنتجات التي لا تملك صورة أصلية تستخدم صورة قسمها.
