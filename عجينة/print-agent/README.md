# Loliz Print Agent

وكيل محلي صغير لطابعات الفواتير الحرارية ESC/POS — سواءً كانت موصولة بكبل شبكة أو بـ USB.

**تنصيب الوكيل:** من مجلد `shop-setup` شغّل `INSTALL.bat` (يسجّله كخدمة ويندوز دائمة).
للتشغيل اليدوي: `start-print-agent.bat`.

## طابعة بكبل شبكة (LAN)

1. صِل الطابعة وجهاز الكاشير بالشبكة نفسها وثبّت IP للطابعة.
2. من الداشبورد: الإعدادات ← طابعة الفواتير ← الوصلة **«كبل شبكة (LAN)»**.
3. أدخل IP الطابعة والمنفذ 9100، اختر 80mm أو 58mm، ثم احفظ وافحص Agent.

## طابعة USB

موديلات مثل **Xprinter XP-T80Q** موصولة USB وليس لها IP إطلاقاً.

1. ثبّت تعريف الطابعة على ويندوز حتى تظهر في «الأجهزة والطابعات».
2. من الداشبورد: الإعدادات ← طابعة الفواتير ← الوصلة **«USB»**.
3. اضغط **«جلب الطابعات»** واختر الطابعة من القائمة، ثم احفظ.

البايتات تُرسل عبر Windows Spooler بنوع البيانات `RAW`، فلا يعيد التعريف رسمها كصفحة.
راجع `raw-print.ps1`. الطباعة عبر USB تعمل على ويندوز فقط.

العربي يُرسم داخل المتصفح كصورة Raster قبل إرساله للطابعة، لذلك لا يعتمد على دعم Code Page عربي في الطابعة. الوكيل يستمع افتراضياً على `127.0.0.1:18181` فقط، ولا يسمح إلا بعناوين LAN محلية وOrigins الموجودة في `config.json`.
