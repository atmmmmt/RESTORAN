# تجهيز جهاز الفرع — الطابعة والبصمة

كل ما يلزم تنصيبه على لابتوب الفرع، بملف واحد.

## المطلوب قبل البدء

| | |
|---|---|
| **Node.js 18+** | من [nodejs.org](https://nodejs.org) — اختر النسخة **LTS** |
| **الطابعة** | إمّا **IP ثابت** إن كانت بكبل شبكة، أو **تعريفها مثبّت على ويندوز** إن كانت USB |
| **IP جهاز البصمة** | ثابت، عادةً `192.168.1.201` |
| **مفتاح الوكيل** | الداشبورد ← الحضور ← الأجهزة ← إضافة جهاز — **يظهر مرة واحدة فقط** |

> لكل فرع مفتاح خاص به. لا تستخدم نفس المفتاح في فرعين.

## التنصيب

انسخ هذه المجلدات الثلاثة معاً على اللابتوب (مثلاً `C:\ajineh`):

```
ajineh\
  shop-setup\
  print-agent\
  attendance-agent\
```

ثم **كليك يمين على `INSTALL.bat` ← تشغيل** (سيطلب صلاحية المسؤول — اضغط نعم).

المثبّت يقوم بكل شيء: يتأكد من Node، يثبّت المتطلبات، يسأل عن مفتاح الوكيل و IP البصمة مرة واحدة، ثم يسجّل الوكيلين كخدمتَي ويندوز.

بعدها من الداشبورد: **الإعدادات ← طابعة الفواتير** — اختر نوع الوصلة:

- **كبل شبكة (LAN):** أدخل IP الطابعة والمنفذ 9100.
- **USB:** اضغط **«جلب الطابعات»** واختر الطابعة من القائمة.

ثم اختر 80mm، اضبط الكثافة على **«غامقة»**، احفظ، واضغط «فحص Agent».

> كل جهاز له إعداده الخاص. إذا كانت طابعة المطبخ بكبل شبكة وطابعة الكاشير USB،
> يُضبط كل جهاز من متصفحه — الإعدادات محفوظة محلياً على كل جهاز على حدة.

## الملفات

| الملف | متى تستعمله |
|---|---|
| `INSTALL.bat` | مرة واحدة عند التجهيز |
| `CHECK.bat` | عند أي مشكلة — يفحص الخدمتين والطابعة وجهاز البصمة |
| `RUN-PRINTER-MANUALLY.bat` | احتياطي: تشغيل وكيل الطابعة بنافذة مفتوحة لرؤية الأخطاء |
| `UNINSTALL.bat` | لإزالة الخدمتين من الجهاز |

## لماذا خدمات وليس نوافذ؟

جهاز الفرع يُطفأ ويُعاد تشغيله، ويُترك على شاشة القفل. أي برنامج يُشغَّل من اختصار يموت مع الجلسة — ويتوقف الحضور أو الطباعة بصمت. الخدمة تبدأ قبل تسجيل الدخول وتعيد تشغيل نفسها عند أي خلل.

## حل المشاكل

| العطل | الحل |
|---|---|
| الفاتورة لا تُطبع | شغّل `CHECK.bat`. إن كان وكيل الطابعة متوقفاً: `INSTALL.bat` من جديد |
| `تعذّر الاتصال بالطابعة` وهي USB | نوع الوصلة في الإعدادات ما زال «كبل شبكة». بدّله إلى **USB** واختر الطابعة بالاسم |
| `تعذّر فتح الطابعة (1801)` | اسم الطابعة تغيّر أو حُذف تعريفها. اضغط «جلب الطابعات» واختر من جديد |
| الفاتورة باهتة | الداشبورد ← الإعدادات ← الكثافة «غامقة جداً». وتأكد من محوّل كهرباء الطابعة الأصلي ومن الورق الحراري |
| `مفتاح الوكيل غير صالح` | ولّد مفتاحاً جديداً من الداشبورد، واحذف `attendance-agent\config.json` ثم شغّل `INSTALL.bat` |
| `تعذّر الاتصال بجهاز البصمة` | تأكد أنه يعمل وأن الـ IP لم يتغيّر: `ping 192.168.1.201` |
| البصمات لا تصل | مشكلة إنترنت. الوكيل يعيد المحاولة تلقائياً ولا تضيع أي بصمة |

**السجلات التفصيلية:** Event Viewer ← Windows Logs ← Application

## ملاحظات

- عنوان جهاز البصمة يُقرأ من السيرفر عند كل مزامنة — تغييره من الداشبورد يكفي، دون لمس اللابتوب.
- إرسال نفس البصمات أكثر من مرة آمن: السيرفر يتجاهل المكرر.
- `attendance-agent\config.json` يحتوي مفتاح الفرع. لا يُرفع على git ولا يُشارك.
- وكيل الطابعة يستمع على `127.0.0.1` فقط، ولا يقبل إلا عناوين LAN محلية والـ Origins المذكورة في `print-agent\config.json`.
