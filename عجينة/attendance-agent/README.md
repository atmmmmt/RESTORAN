# وكيل جهاز البصمة

برنامج صغير بيشتغل على كمبيوتر داخل الفرع، بيقرأ البصمات من جهاز ZKTeco وبيبعتها لسيرفر عجينة وطحينة.

## ليش في وكيل أصلاً؟

السيرفر بمركز بيانات، وجهاز البصمة على شبكة الفرع المحلية بعنوان `192.168.x.x`. السيرفر ما بيقدر يوصل لهاد العنوان — وكل فرع بيستخدم نفس الترقيم، فالعناوين مش فريدة أصلاً.

الوكيل بيقلب الاتجاه: **هو اللي بيتصل بالسيرفر**، زي ما المتصفح بيفتح موقع. النتيجة:

- بدون فتح بورتات على الراوتر
- بدون VPN
- جهاز البصمة بيضل محمي جوّا الشبكة
- تكرار `192.168.1.x` بين الفروع ما بيأثر
- لو قطع النت، البصمات بتضل مخزّنة على الجهاز وبتوصل لما يرجع

## التنصيب

### 1. المتطلبات

Node.js 18 أو أحدث (بيحتاج `fetch` المدمج): https://nodejs.org

```bash
node -v
```

### 2. الملفات

انسخ مجلد `attendance-agent` على كمبيوتر الفرع، مثلاً `C:\ajineh-agent`، وشغّل:

```bash
npm install
```

### 3. الإعدادات

انسخ `config.example.json` باسم `config.json` وعدّله:

```json
{
  "serverUrl": "https://ajenah.prootech-agency.com",
  "agentKey": "المفتاح-من-الداشبورد",
  "deviceIp": "192.168.1.201",
  "devicePort": 4370,
  "syncSeconds": 60,
  "pollSeconds": 5
}
```

**من وين المفتاح؟** من الداشبورد: `الحضور ← الأجهزة ← إضافة جهاز`، اختار الفرع واحفظ. المفتاح بيظهر **مرة واحدة فقط** — انسخه فوراً.

### 4. جرّب

```bash
npm start
```

لازم تشوف:

```
▶ وكيل البصمة يعمل
✓ مزامنة — 12 حركة على الجهاز، 12 جديدة
```

اضغط `Ctrl+C` للإيقاف.

### 5. خلّيه خدمة دائمة

عشان يشتغل مع إقلاع الجهاز وبدون ما حدا يسجّل دخول — **من CMD كمسؤول**:

```bash
npm run install-service
```

للحذف:

```bash
npm run uninstall-service
```

## حل المشاكل

| الرسالة | السبب والحل |
|---|---|
| `مفتاح الوكيل غير صالح` | المفتاح غلط أو انعمله تدوير من الداشبورد. ولّد مفتاح جديد وحدّث `config.json` |
| `تعذّر الاتصال بجهاز البصمة` | الجهاز مطفي، أو الكبل مفصول، أو الـ IP تغيّر. تأكد بـ `ping 192.168.1.201` |
| `تعذّر الوصول للسيرفر` | مشكلة إنترنت بالفرع. الوكيل بيعيد المحاولة تلقائياً — البصمات ما بتضيع |
| `حزمة zkteco-js غير مثبتة` | شغّل `npm install` |

**السجلات كخدمة:** Event Viewer → Windows Logs → Application

## ملاحظات

- عنوان الجهاز بينقرأ من السيرفر عند كل مزامنة، فلو تغيّر بتعدّله من الداشبورد بدون ما تلمس الكمبيوتر.
- كل فرع بدّه **مفتاح خاص فيه**. لا تستخدم نفس المفتاح بفرعين.
- إرسال نفس البصمات أكتر من مرة آمن — السيرفر بيتجاهل المكرر.
